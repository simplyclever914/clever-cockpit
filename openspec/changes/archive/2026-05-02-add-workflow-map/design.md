# Design

The Workflow view is a static explanatory map in the MVP. It uses the existing architecture-card visual language (`arch`, `node`) but renames the concept to workflow.

Key principles:

- Ideas are captured signals, not commitments.
- Decisions convert ideas into either parked notes, tasks, or draft projects.
- Projects group outcomes and require confirmation before activation.
- Tasks are concrete next actions generated from a project or direct idea conversion.
- Results and activity feed back into ideas/projects.
