# add-workflow-map

## Why

The cockpit shows Ideas, Projects, and Tasks as separate views, but their relationship and lifecycle are unclear. The user needs an explicit workflow map similar to the old Architecture section, but focused on product/work tracking rather than system architecture.

## What changes

- Add a dedicated Workflow navigation section/view.
- Explain how ideas become project drafts and tasks.
- Show decision gates, approval points, and feedback loops.
- Clarify that approved ideas create draft projects, not active projects without confirmation.

## Impact

Improves comprehension of Cockpit's core model without changing backend behavior.
