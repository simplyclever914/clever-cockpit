# add-activity-view

## Why

Workflow references Activity as the feedback loop, but the UI only exposes it indirectly through Inbox. That makes the model inconsistent.

## What changes

- Add Activity as a first-class navigation item and view.
- Keep Inbox as attention/triage, but make Activity the chronological log.
- Link Workflow language to the explicit Activity view.

## Impact

UI-only MVP change; no backend changes.
