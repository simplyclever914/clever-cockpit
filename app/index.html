3. Draft projectApproved idea becomes a draft project with outcome + first task. Not active until confirmed.
4. TasksConcrete next actions. Tasks can come from a project or directly from a small approved idea.

Working rules

Idea ≠ commitment

Идея — это captured signal. Она ждёт решения: развивать, превратить в маленькую задачу, отложить или закрыть.

Approved idea → draft project

OK по идее создаёт draft project + first task. Активным проект становится только после подтверждения outcome/приоритета.

Task = next action

Задача должна быть исполнимой: один понятный шаг, статус, привязка к проекту или source idea.

Define before running

У каждой задачи должно быть описание: outcome, scope, done criteria и blocker/trigger. В списках описание спрятано под spoiler, чтобы не шуметь.

Schedules run by default

Расписания делают свою работу без approval, если Вадим явно не поставил gate. Approval нужен для отдельных решений/новых идей.

Approvals are explicit gates

OK/Deny в Approvals не “просто заметка”: runner забирает approved action и выполняет только allowlisted handler.

Activity closes the loop

Каждый запуск, публикация, ошибка или результат попадает в отдельный раздел Activity и может породить новую идею/таск.
